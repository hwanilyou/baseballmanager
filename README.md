# baseballmanager

KBO-style baseball manager simulation game.

## Run locally

```bash
npm start
```

Then open:

```text
http://127.0.0.1:8766/index.html
```

## Files

- `outputs/server.js` - Node.js backend and game simulation
- `outputs/index.html` - frontend UI
- `outputs/data/kbo_players.csv` - player import data
- `outputs/save.json` - current local save state
